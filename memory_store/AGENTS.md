# Memory Store

Some form of structured/semi-structured store of language-formated replica of
what's currently in human brain that can be expressed in human languages.

It's the human memory expressed in human language so that humans can express oneself.

We can use this as form of external store of one's memory so the person can forget
what's going on in one's brain and focus on the work at the moment,
and leave long-term life-time commitment to an agent that operate on these memory.
